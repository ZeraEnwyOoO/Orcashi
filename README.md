# ORCASHI - P2P Chat for iSH + Linux

## Features
- P2P Encrypted Chat
- iSH (iPhone) + Linux Support
- Auto-Detect Mode (Plug / Normal)
- No Server!
- UDP Hole Punching
- Cross-Platform

## Install
```bash
git clone https://github.com/ZeraEnwyOoO/orcashi.git
cd orcashi
g++ -o orcashi orcashi.cpp -lpthread -std=c++17
```

## Usage
```bash
# iSH (iPhone) - Creator
./orcashi create

# Linux - Joiner
./orcashi join <code>
Enter peer IP: 192.168.1.5
```
